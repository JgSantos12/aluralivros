# AluraBooks 📚

Landing page de uma livraria online desenvolvida durante curso da Alura.

## Tecnologias

- HTML
- CSS
- JavaScript
- Swiper.js (carrossel de livros)

## Funcionalidades

- Menu hamburguer responsivo
- Carrossel de últimos lançamentos e mais vendidos
- Seção de tópicos visitados recentemente
- Campo de cadastro de e-mail para newsletter
- Layout responsivo para mobile e desktop

## Sobre

Projeto desenvolvido como exercício prático do curso de HTML e CSS da Alura, focado em responsividade e boas práticas de estruturação HTML.
